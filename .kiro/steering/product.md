# Product Overview

**Expense & Budget Visualizer** is a client-side web application for personal expense tracking and budget visualization.

## Core Features

- **Transaction Management**: Add and delete expense transactions with item name, amount, and category
- **Balance Tracking**: Real-time display of total spending across all transactions
- **Category Organization**: Expenses categorized into Food, Transport, and Fun
- **Visual Analytics**: Chart-based visualization of spending distribution by category
- **Data Persistence**: Local storage for transaction history across sessions

## User Experience

Simple, single-page interface where users can:
1. Enter expense details via a form
2. View all transactions in a list with delete capability
3. Monitor total balance at a glance
4. Analyze spending patterns through category charts
